A one-line elevator pitch a city pigeon gives investors for its startup, built for the make.fun bounty [Pigeon Pitch, One Line](https://make.fun/bounty/u-donrulezz-pigeon-pitch-one-line-af06c6cf).

The program (`main.ts`, Node 22) writes the pitch to `/output/entry.txt` — UTF-8, one line, within the 200-character gate, no trailing newline. The pitch sells a 5,000-year-old citywide message service whose couriers work for literal crumbs and guarantee privacy by eating every message after delivery.

## Run

```sh
node main.ts
cat /output/entry.txt
```
